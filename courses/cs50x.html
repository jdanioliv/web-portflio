Harvard CS50x: Introduction to Computer Science

Fundamentos de ciencias de la computación, gestión de memoria a bajo nivel, estructuras de datos, algoritmos y desarrollo web con Python y SQL.

// Conocimientos Adquiridos por Módulo (Lectures)

Weeks 0 - 2: Lenguaje C, Compilación & Arrays

Representación binaria, tipos de datos estáticos, compilación con clang, funciones, bucles, arrays en memoria contigua, argumentos de línea de comandos (argc, argv) y criptografía básica.

Week 3: Algoritmos & Complejidad (Big O)

Búsqueda lineal vs. búsqueda binaria. Algoritmos de ordenamiento (Bubble Sort, Selection Sort, Merge Sort), recursividad y análisis de eficiencia asintótica ($O(n)$, $O(\log n)$, $\Omega$).

Weeks 4 - 5: Memoria, Punteros & Estructuras de Datos

Direcciones hexadecimales, punteros en C, asignación dinámica de memoria (malloc y free), prevención de fugas de memoria (Valgrind), listas enlazadas (Linked Lists), árboles binarios, Hash Tables y Tries.

Week 6: Transición a Python

Abstracción de alto nivel en Python: listas dinámicas, diccionarios, comprensión de listas, manejo de excepciones y procesamiento rápido de datos y texto.

Week 7: Bases de Datos Relacionales (SQL)

Diseño de esquemas en SQLite, consultas SELECT, JOIN, índices para optimización de búsquedas, claves primarias/foráneas y prevención de ataques de SQL Injection.

Weeks 8 - 9: Desarrollo Web con HTML, CSS, JS & Flask

Protocolo HTTP (GET/POST), arquitectura MVC con Python Flask, plantillas dinámicas con Jinja2, gestión de sesiones de usuario y conexión de backend con bases de datos.
