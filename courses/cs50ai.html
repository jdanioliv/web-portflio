// Temario Técnico & Lectures

Lectures 0 - 2: Functions, Conditionals & Loops

Tipado en Python, métodos de cadenas (str), control de flujo, diccionarios e iteración sobre estructuras de datos.

Lectures 3 - 5: Exceptions, Libraries & Unit Tests

Manejo defensivo de errores (try/except), uso de APIs externas con requests, creación de paquetes y pruebas automatizadas con pytest.

Lectures 6 - 8: File I/O, Regex & Object-Oriented Programming

Lectura/escritura de archivos CSV, validación de patrones con expresiones regulares (re), clases, métodos, propiedades (@property) y herencia en Python.
